# 한지미 HanjaIME 0.8.13

구름 기반 macOS 두벌식 한자·이모지 입력기 개발판입니다. 공식 구름 입력기는 별도로 유지합니다.

설치 전 **설치와사용법.md**를 읽으세요. 판매·후원을 고려한다면 **판매와후원_라이선스검토.md**를 읽으세요.

- 개인 단어 관리를 설정 안에 통합했습니다. 별도 관리 앱은 제공하지 않습니다.
- 일반·입력·개인 단어·사전·정보·라이선스의 상단 아이콘 탭, 더 작은 설정 창, macOS 26 계열 Liquid Glass 질감, 별도 변경 내역 창을 제공합니다.
- GitHub 공개와 Sparkle 2 자동 업데이트 도입 방향은 GITHUB_AUTOUPDATE_PLAN.md에 정리했습니다.
- Apple 사전에 뜻풀이가 없으면 공식 네이버 사전 페이지를 뜻풀이 창 안에서 자동으로 엽니다. 설정 → 사전에서 끌 수 있습니다.
- 날씨 → 天氣·天気 및 뜻 기반 신자체 후보를 제공합니다.
- Unicode CLDR 한국어 사전: 6,058개 키워드, 11,091개 이모지 연결. 기호 분류에서 볼 수 있습니다.
- 미국 🇺🇸🗽, 영국 🇬🇧💷💂 및 관련 국가, 유럽 🇪🇺, 생일·사랑·동물·음식 등.
- 덴마크 丁抹/丹麥, 하늘 天, 바다 海 등 명시적으로 등록한 뜻 기반 한자.
- 두벌식 입력마다 실제 libhangul 배열을 복구합니다. 캐시와 실제 C 입력 상태의 불일치를 방어합니다.
- 두 번째 단어 후보창과 늦게 오는 앱 커서 위치의 재시도 처리를 유지합니다.
- 신규 개인 사전은 비어 있습니다. 기존 사용자의 로컬 사전은 유지합니다.

모든 한국어 단어의 의미를 추론하는 AI 사전은 아닙니다. 이모지 연관성은 언어·문화에 따라 다를 수 있으며 관련 국가를 같은 나라로 취급하지 않습니다. EU 깃발은 유럽 전체의 공식 깃발이 아닙니다.

Apple Silicon용 실행 파일, ad-hoc 서명 개발판입니다. Developer ID 공증·Intel 실행 검증·전체 macOS 버전 호환성 검증은 완료하지 않았습니다. 테스트 결과와 실제 앱별 수동 확인 범위는 VALIDATION.md를 참조하세요.

포함 항목: dist 실행 파일, Sources 수정 소스, CorrespondingSource 전체 macOS 빌드 소스와 의존성, patches 검증용 패치, licenses 원문, tests 회귀 테스트. 개인 학습 데이터·설치 로그·Git 이력은 배포하지 않습니다.
