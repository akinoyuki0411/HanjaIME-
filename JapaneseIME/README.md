# HanjaIME 日本語 0.1.7

独立した macOS 日本語入力方法の試験版です。ローマ字からひらがなへ入力し、SKK-JISYO.L による単語変換で旧字体を先、新字体を後に表示します。

- Space: 変換・次候補。↑ ↓: 候補移動。Enter / 候補番号: 確定。
- Esc: 変換解除、もう一度で読みを消去。F7: カタカナ確定。
- `gakkou` → 學校 / 学校、`tenki` → 天氣 / 天気。
- `n'` は明示的な「ん」、`nn` と促音・拗音も対応。
- 自動候補は設定から切り替え可能。入力内容の保存・送信はありません。

インストール先: `~/Library/Input Methods/HanjaIME 日本語.app`。
設定の「一般」→「日本語入力方法を追加」から登録・有効化を要求できます。システム設定 → キーボード → テキスト入力 → 編集 → + でも追加できます。登録の戻り値だけで追加完了とせず、有効状態も確認します。現在のログインでは登録は成功しても有効化が反映されないケースを確認しています。その場合は作業を保存してログアウト・再ログインした後、再度追加してください。

設定は韓国語版と同じ上部タブ・カード形式です。「一般・入力・辞書・情報・ライセンス」と韓国語／英語／日本語の表示言語を用意しています。

**制限:** 文全体の自動分節・学習辞書は未実装です。旧字体は文化庁の常用漢字表の括弧内字形を使います。全歴史的異体字を網羅しません。日本語の新字体候補を消さず、後順位で残します。

## データ・再ビルド

SKK-JISYO.L は GPL v2 またはそれ以降。原データ、変換した UTF-8 データ、ライセンス、出典・ハッシュを Resources に同梱します。旧字体表の出典は Resources/SOURCES.txt を参照してください。

`python3 JapaneseIME/build.py` で Apple Silicon の macOS 12 以降向けにビルドします。
テスト: `xcrun swiftc JapaneseIME/Sources/JapaneseCore.swift JapaneseIME/Tests/main.swift -o /tmp/japanese-tests`、続いて `/tmp/japanese-tests JapaneseIME/Resources`。
